# Legal Contract Analysis using Transformer NLP

## Project Overview
This project performs:
- Clause Classification
- Risk Prediction
- Legal Contract Analysis

using a custom Transformer-based NLP model.

---

## Features
- Data Cleaning & Preprocessing
- Lemmatization
- Tokenization
- Transformer Architecture
- Multi-output Classification
- Clause-level Risk Detection

---

## Technologies Used
- Python
- TensorFlow / Keras
- NLP
- Google Colab
- Scikit-learn
- NLTK

---

## Transformer Architecture
The model includes:
- Embedding Layer
- Positional Encoding
- Multi-Head Self Attention
- Feed Forward Network

---

## Dataset
Dataset contains legal clauses with:
- Clause Type
- Risk Level

Approximate dataset size:
- 9000 records

---

## Results
- Risk Classification Accuracy: ~91%
- Clause Type Accuracy: ~71%

---

## Future Improvements
- BERT-based classification
- Contract-level classification
- Explainable AI for legal risk
